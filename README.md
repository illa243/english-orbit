# English Orbit · Windows / Qt

Утиліта для вивчення англійської на Windows із Qt-інтерфейсом месенджера, AI-персонажами, пам’яттю та практикою повторюваних помилок.

Експериментальна версія для Windows 10/11 x64. Потрібні Python 3.12 x64 та інтернет для встановлення залежностей. AI-функції потребують власного акаунту з доступом до відповідного офіційного CLI; звичайна підписка не гарантує доступ до всіх клієнтів і моделей.

## Встановлення з GitHub

1. Натисніть **Code → Download ZIP** та розпакуйте у папку з правом запису, наприклад `D:\EnglishOrbit`.
2. Встановіть [Python 3.12 для Windows](https://www.python.org/downloads/windows/) з Python Launcher.
3. Відкрийте PowerShell у папці проєкту та виконайте:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

Скрипт створює локальне Python-середовище, завантажує Node.js з nodejs.org із перевіркою SHA-256, встановлює офіційні AI-клієнти за lock-файлом і збирає невеликий Windows launcher. Залежності завантажуються у папку проєкту; потрібне вільне місце на диску. Після успіху відкрийте `EnglishOrbit.exe` або `launch.vbs`.

Якщо Python Launcher відсутній:

```powershell
.\setup.ps1 -PythonPath "C:\шлях\до\python.exe"
```

Це запуск із вихідного коду, а не автономний інсталятор. Windows може показати попередження для непідписаного launcher. У репозиторії немає чужих профілів, переписок або сесій; кожен користувач створює власний профіль і входить у власні акаунти.

## Запуск

Відкрийте **EnglishOrbit.exe** або ярлик **English Orbit** на робочому столі. Альтернатива — `launch.vbs`.

Під час першого запуску введіть ім’я, рівень, мету українською та за бажанням аватар. Потім підключіть AI-провайдера і перевірте джерела збору. Програма залишається в треї після закриття. Вихід — через меню трея.

## AI-підписки

Налаштування → AI-підписки → **Підключити**. Відкривається незмінений офіційний клієнт відповідного провайдера. Вхід завершується користувачем у браузері/клієнті. Вибирайте підписку або Google sign-in, не API billing. Після входу моделі оновлюються автоматично. Збережена сесія відновлюється без повторного входу; кнопка «Вийти» відключає її.

- ChatGPT: Codex CLI / app-server, читання account та model/list.
- Claude: офіційний Claude Code, перевірка auth status, каталог через SDK control initialization.
- Gemini: офіційний Gemini CLI, Google OAuth, каталог через ACP session/new.

Моделі не визначаються за вигаданою таблицею тарифів. Якщо каталог недоступний, залиште поле моделі порожнім: використовується вибір офіційного клієнта. Доступ остаточно перевіряється провайдером під час запиту. Ліміти відображаються лише коли клієнт їх надає. За помилки запит зберігається, інший провайдер автоматично не вибирається.

Програма не використовує API-ключі. Налаштування платного перевищення ліміту/extra usage у самому акаунті провайдера слід вимкнути, якщо потрібна повна відсутність витрат понад підписку: клієнти не надають універсального способу керувати цим із нашого застосунку.

Сесії окремі від поточних установок: `data/providers`. Токени не виводяться в UI та не входять у резервну копію. Реальні запити всіх трьох провайдерів потребують вашого входу; без нього не можна підтвердити доступ конкретної підписки.

## Chrome

1. Відкрийте `chrome://extensions` і ввімкніть режим розробника.
2. «Завантажити розпаковане розширення» → `D:\EnglishOrbit\chrome-extension`.
3. У налаштуваннях утиліти → Збір текстів → скопіюйте код підключення.
4. Відкрийте розширення, вставте код і натисніть «Підключити».
5. Дозвольте потрібні домени в розширенні; ті самі домени мають бути в налаштуваннях утиліти. Перезавантажте вкладки.

Розширення передає лише редаговані поля на локальний порт 18743, із секретним кодом. Не читає паролі. Зберігає поточний текст, а не послідовність клавіш. Форму/очищення поля трактує як завершення промпту; Enter сам по собі не є відправленням. Якщо сайт зберігає composer після відправлення, скористайтеся контекстним меню «save for analysis».

## Windows-застосунки

Перелік налаштовується за іменами процесів. Типові: codex.exe, chatgpt.exe, claude.exe, telegram.exe, discord.exe. Автоматичне читання залежить від доступності editable ValuePattern/TextPattern у Windows UI Automation. Не всі Electron-композери надають такий доступ; перевірка кожної версії клієнта на вашому ПК залишається необхідною.

- **Ctrl+Alt+S** — зберегти виділений текст для аналізу.
- **Ctrl+Alt+W** — додати виділене слово/фразу.

Якщо виділення недоступне через UI Automation, вікно запропонує вставити текст вручну. Буфер обміну не перезаписується. У Chrome доступні аналогічні команди контекстного меню.

## Навчання

- 20 секунд без редагування → локальний запис. Продовження оновлює той самий запис, відправлення/очищення починає наступний.
- **Analyze** надсилає лише вибраний текст. Код/логи/цитати попередньо прибираються консервативним фільтром; перевірте поле перед відправленням.
- Мінімальні правки та природна версія розділені. Розбір прив’язаний до версії.
- Практика: 3–5 завдань, підказка, друга спроба, пояснення. Голосові функції не входять у цю версію.
- Слова додаються після підтвердження перекладу. Напрямок en→uk починається першим; uk→en з’являється через день після успіху.
- Повторення: 1/3/7/14/30/60/120 днів після правильних відповідей; описка — через 30 хвилин, неправильна відповідь — через 10 хвилин. Це початковий алгоритм, не FSRS.
- Кожен персонаж бачить лише свій чат та спільний навчальний профіль. `.md` файли — в `agents`.
- Випадкові ініціативні повідомлення в дозволені години, без повторного нагадування про непрочитане. Спливне вікно чекає 20 секунд без активності (Windows idle враховує також мишу).

## Дані та резервні копії

SQLite: `data/orbit.sqlite`. Непроаналізовані незакріплені тексти видаляються через 7 днів після редагування. Експорт/імпорт — у налаштуваннях. Перед імпортом поточна база резервується; збір після імпорту вимикається. Експорт містить особисті тексти, тому зберігайте архів у довіреному місці. Ключі підключення й AI-сесії не експортуються.

## Розробка та перевірка

Qt 6.12 / PySide6, Python 3.12, SQLite. Runtime, npm tools і кеші — у папці встановлення. Код модулів: `core.py`, `providers.py`, `capture.py`, `ui.py`, `main.py`.

```powershell
& .\.qt-env\Scripts\python.exe -m pip install -r requirements-dev.txt
& .\.qt-env\Scripts\python.exe -m pytest tests -q
& .\runtime\node\node.exe --test tests\extension.test.cjs
& D:\EnglishOrbit\.qt-env\Scripts\python.exe D:\EnglishOrbit\main.py --demo --smoke --screenshot D:\EnglishOrbit\test-output\chat-preview.png
```

`--demo` використовує окрему тестову базу з явно демонстраційними повідомленнями. У реальній базі немає вигаданих AI-відповідей. Тести перевіряють локальну логіку, екрани, відмову без авторизації, розділення чатів та захист локального HTTP-моста; вони не замінюють перевірку реальних підписок.

Chrome-розширення встановлюється вручну через дозволи браузера. Програма не змінює профіль Chrome і не намагається обходити вхід чи підтвердження провайдерів.

## Пам’ять і персональна практика

- У чаті → «Допоможи сформулювати»: конструкція, початок речення, повний приклад. Підказка не надсилається автоматично. Наступна відповідь після підказки враховується як відповідь із допомогою.
- «Практика» показує кількість помилок, правильних самостійних використань і відповідей із допомогою. Облік починається з нових розборів та повідомлень після оновлення; старі конструкції не отримують вигаданих оцінок.
- До розмов та ініціативних повідомлень передаються три пріоритетні конструкції. Персонаж отримує інструкцію природно створювати нагоду використати одну з них.
- «Пам’ять» у заголовку чату: перегляд, редагування й видалення фактів цього персонажа. Факти витягуються лише з останнього повідомлення користувача з дослівним підтвердженням. Видалена тема блокується для повторного запам’ятовування й передається моделі як заборонена для використання зі старої історії. Це не видаляє самі повідомлення з історії.
- Статистика та пам’ять зберігаються локально й входять до резервної копії. Для відповіді AI отримує пам’ять тільки поточного співрозмовника. Якість розпізнавання конструкцій і фактів залежить від обраної моделі.

## Чати

ПКМ на повідомленні: Reply, Pin/Unpin, Copy Text, Delete. Іконка біля закріпленого повідомлення відкриває список закріплених; натискання повертає до повідомлення в чаті. Статус online означає підготовку AI-відповіді, last seen recently з’являється через 3–7 секунд після неї; це симуляція присутності персонажа.
